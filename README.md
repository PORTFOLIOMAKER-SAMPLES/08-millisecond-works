## 개발 포트폴리오는 무엇을 담아야 하나

2026년 채용 담당자들이 실제로 본다고 알려진 형식을 그대로 반영했습니다.

- **원페이지 · 프로젝트 우선** — 스크롤 한 번에 전부 스캔됩니다
- **프로젝트마다 문제 → 접근 → 결과** — "백엔드 성능 개선"이 아니라 "LCP 4.8s → 0.9s, 예약 완료율 +23%"
- **수치가 있는 결과** — 여섯 개 카드 전부 측정값으로 끝납니다
- **저장소 링크** — 카드를 열면 GitHub 주소가 나옵니다
- **다크 기본 + 모노 악센트** — 카본 테마와 Geist 조합
- **기술 스택은 태그로** — 문장이 아니라 훑어보는 형태로

이 구조가 그대로 편집기의 파트 조합으로 만들어집니다. 갤러리 카드의 제목 · 스택 · 요약 · 상세는 각각 별도 입력칸입니다.

## 직접 열어서 뜯어보기

1. [portfoliomaker.site](https://portfoliomaker.site) 접속
2. 상단 **저장 · 불러오기** 아이콘 클릭
3. **파일에서 불러오기** → 이 저장소의 `millisecond-works.pbproj` 선택

프로젝트 카드 내용만 본인 것으로 바꾸면 바로 쓸 수 있는 개발자 포트폴리오가 됩니다.

## Portfolio Maker 는 어떤 도구인가요

- **설치 없음 · 가입 없음** — 브라우저에서 바로 시작합니다
- **틀 → 내용 → 꾸미기 → 내보내기** 네 단계로 끝납니다
- 테마 18종, 글꼴 10종, 파트 15종 이상을 조합합니다
- 3D 모델(`.glb`) 뷰어, 무료 사진 검색, 다크/라이트 토글이 기본 제공됩니다
- 결과물은 **단일 HTML** 또는 **폴더 ZIP** 으로 내려받습니다 — 이 저장소가 그 ZIP 그대로입니다
- 빌드 도구 없이 정적 파일이라 GitHub Pages에 그대로 올라갑니다

## 경력 개발 스튜디오는 무엇으로 증명하나

- **원페이지 · 프로젝트 우선** — 스크롤 한 번에 전부 스캔됩니다
- **프로젝트마다 문제 → 접근 → 결과** — "백엔드 성능 개선"이 아니라 "LCP 4.8s → 0.9s, 예약 완료율 +23%"
- **트러블슈팅 7건을 따로** — `Process` 페이지에 N+1 쿼리(41 → 2), 폰트 720KB → 88KB, 결제 중복 300건 → 11건 같은 사례를 문제·접근·결과로
- **스택을 카테고리로** — 프론트엔드(주력) / 백엔드·데이터 / 인프라·측정
- **일하는 순서 공개** — 5단계 일정과 계약 기준(최소 4주 · 주 1회 배포 · 성능 3개월 무상 보증)을 숫자로
- **가용 상태 명시** — 분기별 수용 가능 프로젝트 수
- **저장소 링크** — 카드를 열면 GitHub 주소가 나옵니다

> 신입 개발자용 구성은 **[09](https://github.com/PORTFOLIOMAKER-SAMPLES/09-first-commit)**(프론트엔드) 와 **[10](https://github.com/PORTFOLIOMAKER-SAMPLES/10-quiet-server)**(백엔드·안드로이드) 을 참고하세요. 실무 성과 대신 학습 과정과 장애 복구 경험 중심으로 짜여 있습니다.

## 직접 열어서 뜯어보기

1. [portfoliomaker.site](https://portfoliomaker.site) 접속
2. 상단 **저장 · 불러오기** 아이콘 클릭
3. **파일에서 불러오기** → 이 저장소의 `millisecond-works.pbproj` 선택

프로젝트 카드 내용만 본인 것으로 바꾸면 바로 쓸 수 있습니다.

## Portfolio Maker 는 어떤 도구인가요

- **설치 없음 · 가입 없음** — 브라우저에서 바로 시작합니다
- **틀 → 내용 → 꾸미기 → 내보내기** 네 단계로 끝납니다
- 테마 18종, 글꼴 10종, 파트 15종 이상을 조합합니다
- 3D 모델(`.glb`) 뷰어, 무료 사진 검색, 다크/라이트 토글이 기본 제공됩니다
- 빌드 도구 없는 정적 파일이라 GitHub Pages에 그대로 올라갑니다
